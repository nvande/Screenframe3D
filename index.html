The “app” is the library.

This page is dressed like a startup because that’s the job: make a product feel inevitable. Underneath, it’s a few lines of Screenframe3D.

/posters/boot.js preloads every captured still, then the page picks the one whose name matches this screenshot and device. 

import { DeviceShowcase } from 'screenframe3d/react'

<DeviceShowcase
  screenshot="/screenshot.png"
  device="apple/iphone-5s"
  zoom={1.8}
  baseTilt={{ x: 0.12, y: -0.38, z: -0.06 }}
/>

import { screenframe } from 'screenframe3d/vite'
export default { plugins: [screenframe()] }
